# Privacy Policy

Boss runs locally inside the user's coding-agent workspace. The plugin does not include telemetry, analytics, advertising identifiers, or a remote service operated by the maintainer.

The installer writes skill files, hooks, and local state only on the user's machine. Any repository contents, prompts, logs, artifacts, or credentials remain under the user's own agent, shell, package manager, and hosting provider configuration.

If a future release adds networked features, this policy should be updated before those features ship.
